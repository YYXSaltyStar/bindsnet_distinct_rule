# 脉冲神经网络对比实验

本目录包含了自定义空间学习网络与DiehlAndCook2015基线模型的对比实验代码。

## 文件说明

- `batch_eth_mnist.py` - 原始的自定义空间学习网络实现
- `comparison_batch_eth_mnist.py` - 网络对比实验脚本
- `snn_utils.py` - 自定义空间学习规则实现

## 快速开始

### 运行对比实验

```bash
# 完整训练和测试（推荐用于正式实验）
python comparison_batch_eth_mnist.py --train --n_epochs 5 --n_train 60000 --n_test 10000

# 快速测试（用于验证代码）
python comparison_batch_eth_mnist.py --train --n_epochs 1 --n_train 1000 --n_test 1000

# 仅测试（使用未训练的网络）
python comparison_batch_eth_mnist.py --test --n_test 1000
```

### 主要参数

- `--train` / `--test`: 选择训练或测试模式
- `--n_epochs`: 训练轮数
- `--n_train`: 训练样本数量
- `--n_test`: 测试样本数量
- `--n_neurons`: 神经元数量（默认100）
- `--batch_size`: 批次大小（默认32）
- `--gpu`: 启用GPU加速

## 网络架构对比

### 自定义空间学习网络
- **特点**: 使用自定义的SpatialLearningRule学习规则
- **层结构**: 输入层(X) → 兴奋层(E) → 抑制层(I)
- **学习规则**: 空间邻域增强的STDP学习
- **连接**: 输入到兴奋层使用空间学习，兴奋抑制层间使用固定连接

### DiehlAndCook2015基线网络
- **特点**: 经典的Diehl & Cook 2015论文实现
- **层结构**: 输入层(X) → 兴奋层(Ae) → 抑制层(Ai)
- **学习规则**: 标准PostPre STDP学习
- **连接**: 标准的全连接架构

## 性能分析

### 当前观察
1. **基线网络优势**: 在小样本测试中，DiehlAndCook2015基线网络表现更好
2. **训练效率**: 基线网络训练速度更快（105.24 it/s vs 57.27 it/s）
3. **空间学习潜力**: 自定义网络的空间学习特性可能需要更多训练数据才能显现优势

### 改进建议
1. **增加训练样本**: 使用完整的60000个训练样本
2. **调整超参数**: 优化学习率、邻域半径等参数
3. **延长训练时间**: 增加训练轮数以充分学习空间特征
4. **网络结构优化**: 调整神经元数量和连接权重

1. **CUDA内存不足**: 减少batch_size或使用CPU模式
2. **导入错误**: 确保snn_utils.py在同一目录下
